# A little space for your ideas.

Less interface. More clarity. **MD Lite** reads and edits Markdown in a calm, precise, and entirely native experience.

> [!TIP]
> Press **Ctrl+E** to edit this very text and **Ctrl+/** to see every shortcut.

## Three ways to look

| Mode | Shortcut | What for |
| --- | :---: | --- |
| Reading | Ctrl+1 | Read the finished document |
| Editor | Ctrl+2 | Write with formatting in view |
| Source | Ctrl+3 | See and edit plain Markdown |
| Split | Ctrl+4 | Source and reading side by side |

In the editor, markers such as `**` or `#` appear only on the line you are typing. **Ctrl+Z** undoes and **Ctrl+Shift+Z** redoes.

## The essentials, done well

- [x] Open a file with **Ctrl+O** or drop it into the window.
- [x] Save with **Ctrl+S**; open files save themselves.
- [x] Open a folder with **Ctrl+Shift+O** and each document in its own tab (**Ctrl+T**).
- [ ] Check this task with a click.

## Made for Linux

GTK 4 on the surface. Rust in every line. No accounts, no services, no distractions. Explore the [Markdown guide](https://www.markdownguide.org/basic-syntax/) or the [GFM spec](https://github.github.com/gfm/).
